IoT Assessment S1 – Project Codebase (Evidence of Code)
-------------------------------------------------------

Project: Human Activity Recognition (HAR)

ABOUT THIS CODEBASE
-------------------
This folder contains the source code developed for our IoT assessment. Our project explores how accelerometer and gyroscope readings from smartphone sensors can be used to recognise four physical activities: ascending stairs, descending stairs, push-ups and sit-ups.

The codebase brings together the machine learning approaches developed by our group:

- K-Nearest Neighbours (KNN)
- Random Forest
- Logistic Regression
- Convolutional Neural Network (CNN)

WHAT YOU CAN FIND HERE
----------------------
The files provide the Python code used to prepare sensor data, train activity-classification models and evaluate their predictions, where applicable to each model. The associated scripts and contain the implementation details supporting the methods and results presented in our assessment.

Our project also investigates data poisoning: the deliberate alteration of dataset values and activity labels to explore how unreliable training data can affect model performance. Relevant code and experiment files are included where supplied in this codebase.

USING THE FILES
---------------
Open the relevant Python script (.py) to review an individual model. If running the code, ensure that its required Python libraries are installed and that any referenced CSV datasets are available at the file paths specified in the code.

SUBMISSION PURPOSE
------------------
This codebase is provided as supporting evidence for our IoT Assessment S1 presentation. It allows the assessor to inspect the implementations behind our activity-recognition models and associated experiments.
